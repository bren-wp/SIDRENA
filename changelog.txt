Sidrena changelog

= 1.0.10 =
* Upgrade/repair lifecycle premješten je na `init` prije javnog-page repaira, čime se uklanja stvarni WP-CLI/Plugin Check fatal pri preranoj izradi stranice i prerano učitavanje prijevoda.
* Dodan je službeni WordPress Plugin Check workflow za oba stvarna produkcijska paketa; provjera koristi stvarne edition slugove, a jedino je svjesno izuzet policy-only trademark upozorenje za postojeće kompatibilne folder slugove.
* Obradjen je dostavljeni Plugin Check izvještaj: dodani su translators komentari, ispravljen escaping javnih URL-ova, pojačana sanitizacija GET/POST ulaza i uvedeni sigurniji SQL identifier placeholderi za plugin tablice.
* Uklonjen je zastarjeli ručni load_plugin_textdomain poziv; WordPress automatski učitava prijevode za instalacijski text domain.
* WPML integracijski hookovi ostaju nepromijenjeni kao vanjski API hookovi, uz precizne PHPCS napomene.
* SIDRENA S + sidro znak, WordPress/WooCommerce lockupi, favicon, app icon i menu icon dodatno su precrtani prema dostavljenom brand-boardu.
* Admin hero sada koristi jedan kanonski SIDRENA logo i zasebnu edition oznaku radi dosljednog identiteta u oba plugina.
* WordPress.org short description i Description dio readmea prebačeni su na standardni engleski; runtime sučelje ostaje hrvatsko.
* README sada prikazuje obnovljene hero assete uz stvarne wp-admin screenshotove.
* Dodan je Plugin Check regression guard za prijevode, escaping, zastarjeli translation loader i SQL uninstall identifikatore.
* Uklonjen je zastarjeli razvojni 0.1.0 komentar iz produkcijskog frontend CSS-a; runtime sloj više ne sadrži takve razvojne version markere.
* Dodan je regresijski test koji čuva upgrade repair na `init` i sprječava povratak prerane `plugins_loaded` migracije.
* Službeni WordPress Plugin Check potvrđen je uspješnim za oba stvarna 1.0.10 produkcijska paketa nakon popravaka dostavljenog izvještaja.
* Stvarni WordPress i WooCommerce screenshot/branding pipeline ponovno je prošao na finalnom 1.0.10 UI sloju.
* Oba plugina podignuta su na 1.0.10.

= 1.0.9 =

* Asset URL-ovi više ne ovise o krhkom ručnom spajanju SIDRENA_URL putanje nego koriste plugins_url() uz stvarnu plugin ulaznu datoteku.
* CSS i JS dobivaju filemtime cache-busting uz verziju plugina, pa nadogradnja ne ostavlja zastarjeli 1.0.8 izgled u browser/proxy cacheu.
* Obnovljen je cijeli runtime logo sustav: S + sidro znak, WordPress i WooCommerce lockupi, svijetle/tamne varijante, app ikona i zaseban 20×20 admin-menu znak.
* Admin hero je smanjen i usklađen s referentnim prikazima; kartice, metrike, tipografija i razmaci dodatno su ispolirani bez paralelnog override CSS sloja.
* Menu ikona ima vlastite dimenzije, poravnanje i active-state tretman kako više ne bi izlazila iz WordPress menu retka.
* CI i distribution guard sada provjeravaju brand.css, admin.js i edition-specific runtime logo assete unutar stvarnog instalacijskog ZIP-a.
* Dodan je admin-assets smoke test za page-query fallback, screen-id fallback i service editor asset routing.
* Stvarni wp-env screenshot pipeline sada na svih šest glavnih SIDRENA ekrana i na 1440/1180/782/390 px provjerava da su brand.css i admin.js stvarno učitani, da hero/kartice imaju produkcijski computed-style te da menu ikona ne prelazi 20 px.
