Sidrena changelog

= 1.0.3 =
* WooCommerce izdanje deklarira provjerenu kompatibilnost s High-Performance Order Storage (HPOS) značajkom `custom_order_tables` preko službenog WooCommerce FeaturesUtil API-ja.
* Dodan je regression guard koji sprječava WooCommerce deklaraciju u standalone WordPress izdanju i sprječava neprovjerene deklaracije za druge WooCommerce značajke.
* Realni WooCommerce QA sada s aktivnom SIDRENA uključuje HPOS, potvrđuje da WooCommerce registrira dodatak kao kompatibilan te izvodi create/read/delete narudžbe preko WooCommerce CRUD API-ja.
* Database schema marker ostaje 0.2.0; 1.0.3 ne uvodi migraciju podataka.

= 1.0.2 =
* Standalone CSV import sada čita upload izravno kao stream iz privremene datoteke uz bounded obradu redaka, bez učitavanja cijelog importa u memoriju.
* CSV delimiter/dialect obrada dodatno je učvršćena za PHP 8.4, uz regression testove za rubne i neispravne ulaze.
* WooCommerce import sada batchira product-code lookupove kako bi veliki uvozi izbjegli nepotrebno ponavljanje kataloških dohvaćanja.
* Dnevni product i service price-history snapshoti koriste bounded ID keyset iteraciju umjesto page/OFFSET paginacije.
* Zajednički published-post keyset iterator centraliziran je u Sidrena_Utils i ponovno se koristi u history i export putovima, čime je uklonjen duplicirani kod.
* Produkcijski Woo product i service CSV/XML export više ne koristi page/OFFSET iteraciju, uz očuvana publish/visibility/filter/variation pravila i postojeći javni format.
* Database schema marker ostaje 0.2.0; 1.0.2 ne uvodi destruktivnu migraciju podataka.
* WordPress admin sidebar, aktivni SIDRENA menu item, hover/focus stanja i top-level ikona sada koriste isključivo WordPress core/admin color scheme; SIDRENA brending ostaje unutar sadržaja plugin stranica.
* Release se ponovno validira na PHP 7.4/8.3/8.4, WPCS/PHPStan, distribution/legal/admin guardovima, oba WordPress Plugin Check paketa i stvarnom wp-admin QA okruženju.

= 1.0.1 =
* Centralizirana je invalidacija Woo REST membership cachea za izravne promjene _sidrena_cjenik_visibility meta podatka, uključujući REST i third-party integracije.
* Fizičke poslovnice više ne materijaliziraju cijeli skup dostupnih ID-eva u REST hot pathu: candidate retci čitaju se keyset-batch iteratorom uz očuvan WooCommerce redoslijed varijacija.
* Pojedinačni location override sada se dohvaća ciljanim indexed upitom po location/product/variation ključu i request-local cacheom umjesto učitavanja svih redaka poslovnice.
* Uklonjeni su nekorišteni full-location/full-ID helperi iz javnog REST puta kako bi potrošnja memorije ostala bounded na velikim katalozima.
* Dodani su regression testovi za direct-meta invalidation, streaming fizičkih lokacija, targeted lookup i stabilan variation ordering.
* Javni REST odgovor i postojeći podaci ostaju kompatibilni; promjena je fokusirana na skalabilnost, stabilnost i konzistentnu invalidaciju cachea.
* Najniža cijena prethodnih 30 dana sada koristi točan indeksirani `MIN(price)` agregat nad cijelim relevantnim prozorom bez 2000-row truncationa; parent/simple povijest strogo isključuje variation zapise, inference početka sniženja nema 500-row cutoff, a CSV izvoz povijesti koristi stabilne keyset snapshot batchove umjesto OFFSET paginacije.
* Schema marker 0.2.0 dodaje idempotentne product/variation/service sequence indekse potrebne za exact boundary upite i siguran 1.0.0 → 1.0.1 upgrade.
* Administratorski HTTP self-check javnih SIDRENA datoteka sada zahtijeva isti scheme/host/port, kanonski put unutar SIDRENA uploads baze, blokira query/fragment i redirecte te zadržava timeout i response-size limit.
* Ispravljena je fizička-location REST capability provjera tako da koristi streaming `iterate_available_item_ids_for_location` helper, a regression test više ne dopušta povratak na uklonjenu full-ID putanju.
* Release pipeline za 1.0.1 sada sigurno osvježava postojeći current-version tag samo s release brancha koji je identičan `main`, uz force-with-lease, ponovljivi dvostruki build i byte-for-byte provjeru ZIP/.sha256 izlaza prije objave.

= 1.0.0 =
* Konsolidirano produkcijsko izdanje SIDRENA sustava s dva odvojena instalacijska plugina i jednim javnim brojem verzije 1.0.0.
* Središnji podatak je SIDRENA/sidrena referentna cijena, jasno odvojena od aktualne cijene, WooCommerce regular/sale/current lifecyclea i najniže cijene prethodnih 30 dana.
* Zakonski referentni datumi 10.09.2026. i 02.05.2025. zaključani su u backend rulesetu; stare administratorske vrijednosti čuvaju se samo kao audit-only migracijski zapis.
* Nova stavka može dobiti item-level iznimku samo iz dokazivog datuma prvog objavljivanja; iznimka nikad ne postaje globalna postavka.
* Digitalni cjenik ima odvojeni current/archive lifecycle, content-hash duplicate detection, atomic write, process lock, rollback i očuvanje zadnje valjane javne verzije.
* Arhiva se čuva najmanje 30 dana i može se produljiti; intraday osvježavanje aktualnog cjenika ne stvara nepotrebne arhivske kopije.
* Povijest cijena proizvoda, usluga, varijacija i lokacijskih cijena ostaje neograničena, dok dashboard/import/publication slojevi koriste bounded čitanja i batch obradu.
* Standalone katalog podržava proizvode i usluge, više lokacija, siguran CSV/XML uvoz/izvoz, mjerne jedinice, jedinične cijene, javni HTML, REST i strojno čitljive cjenike.
* Standalone import više ne gradi cijeli indeks kataloga u memoriji: redovi se obrađuju u chunkovima, a lookup šifri ograničen je na traženi skup.
* WooCommerce izdanje podržava simple/variable proizvode, svaku variation, regular/sale/current lifecycle, scheduled sale prijelaze, import i promjene price meta podataka.
* Woo bulk editor sada server-side odbija negativne sidrene cijene, količine i jedinične cijene te ograničava broj obrađenih redaka po zahtjevu.
* Cijene usluga po lokaciji prihvaćaju samo kanonske aktivne lokacije; proizvoljni location ključevi više se ne spremaju u meta podatke.
* Upload provjera koristi stvarnu server-side veličinu privremene datoteke, MIME/ekstenziju, encoding i row-limit provjere prije obrade.
* REST koristi validirane argumente, bounded paginaciju, kanonsko mapiranje javnog location codea i ne izlaže nepotrebne interne podatke.
* Dnevna objava podržava interni WP-Cron ili vanjski server cron/WP-CLI, uz compliance/automation watchdog, Site Health, audit i failure notifications.
* Production hardening obuhvaća strožu ulaznu validaciju, bounded batch obradu, sigurnije lokacijske selektore, reproducible build i release provjere.
* External server cron / WP-CLI način sada je potpuno mode-aware i u dashboardu/Cjenicima: izostanak internog dnevnog WP-Crona više se ne prikazuje kao greška kada je external scheduler namjerno odabran.
* Svi administratorski CSV exporti koriste zajednički provjereni output stream, sanitizirani naziv datoteke, nosniff zaglavlje i eksplicitnu provjeru otvaranja/BOM zapisa prije izvoza.
* WooCommerce javni REST cjenik cacheira bounded ravni indeks javnih product/variation ID-eva, invalidira ga na Woo CRUD/status/delete događajima i bulk promjenama te izbjegava ponovno skeniranje cijelog kataloga za svaku sljedeću stranicu.
* Deaktivacija ne briše poslovne podatke; uninstall ima eksplicitnu politiku zadržavanja ili namjernog brisanja podataka.
* Oba izdanja zadržavaju javne slugove/text-domainove i svugdje se korisniku predstavljaju kao SIDRENA.
* Plugin nema premium module, paywall, trial, license key, telemetriju, skriveni tracking ni remote executable code.
