Sidrena changelog

= 1.0.0 =
* Konsolidirano produkcijsko izdanje SIDRENA sustava s dva odvojena instalacijska plugina i jednim javnim brojem verzije 1.0.0.
* Središnji podatak je SIDRENA/sidrena referentna cijena, jasno odvojena od aktualne cijene, WooCommerce regular/sale/current lifecyclea i najniže cijene prethodnih 30 dana.
* Zakonski referentni datumi 10.09.2026. i 02.05.2025. zaključani su u backend rulesetu; stare administratorske vrijednosti čuvaju se samo kao audit-only migracijski zapis.
* Nova stavka može dobiti item-level iznimku samo iz dokazivog datuma prvog objavljivanja; iznimka nikad ne postaje globalna postavka.
* Digitalni cjenik ima odvojeni current/archive lifecycle, content-hash duplicate detection, atomic write, process lock, rollback i očuvanje zadnje valjane javne verzije.
* Arhiva se čuva najmanje 30 dana i može se produljiti; intraday osvježavanje aktualnog cjenika ne stvara nepotrebne arhivske kopije.
* Povijest cijena proizvoda, usluga, varijacija i lokacijskih cijena ostaje neograničena, dok dashboard/import/publication slojevi koriste bounded čitanja i batch obradu.
* Standalone katalog podržava proizvode i usluge, više lokacija, siguran CSV/XML uvoz/izvoz, mjerne jedinice, jedinične cijene, javni HTML, REST i strojno čitljive cjenike.
* Standalone import više ne gradi cijeli indeks kataloga u memoriji: redovi se obrađuju u chunkovima, a lookup šifri ograničen je na traženi skup.
* WooCommerce izdanje podržava simple/variable proizvode, svaku variation, regular/sale/current lifecycle, scheduled sale prijelaze, import i promjene price meta podataka.
* Woo bulk editor sada server-side odbija negativne sidrene cijene, količine i jedinične cijene te ograničava broj obrađenih redaka po zahtjevu.
* Cijene usluga po lokaciji prihvaćaju samo kanonske aktivne lokacije; proizvoljni location ključevi više se ne spremaju u meta podatke.
* Upload provjera koristi stvarnu server-side veličinu privremene datoteke, MIME/ekstenziju, encoding i row-limit provjere prije obrade.
* REST koristi validirane argumente, bounded paginaciju, kanonsko mapiranje javnog location codea i ne izlaže nepotrebne interne podatke.
* Dnevna objava podržava interni WP-Cron ili vanjski server cron/WP-CLI, uz compliance/automation watchdog, Site Health, audit i failure notifications.
* Production hardening obuhvaća strožu ulaznu validaciju, bounded batch obradu, sigurnije lokacijske selektore, reproducible build i release provjere.
* External server cron / WP-CLI način sada je potpuno mode-aware i u dashboardu/Cjenicima: izostanak internog dnevnog WP-Crona više se ne prikazuje kao greška kada je external scheduler namjerno odabran.
* Svi administratorski CSV exporti koriste zajednički provjereni output stream, sanitizirani naziv datoteke, nosniff zaglavlje i eksplicitnu provjeru otvaranja/BOM zapisa prije izvoza.
* Deaktivacija ne briše poslovne podatke; uninstall ima eksplicitnu politiku zadržavanja ili namjernog brisanja podataka.
* Oba izdanja zadržavaju javne slugove/text-domainove i svugdje se korisniku predstavljaju kao SIDRENA.
* Plugin nema premium module, paywall, trial, license key, telemetriju, skriveni tracking ni remote executable code.
