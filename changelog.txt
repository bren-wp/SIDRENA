* Distribucija ostaje isključivo na dva plugina: Sidrena WordPress i Sidrena WooCommerce.

= 0.5.0 =
* Dodan je zaseban GitHub Actions distribution guard koji provjerava izvorni repozitorij i stvarni build izlaz.
* Guard eksplicitno dopušta samo dva instalacijska ZIP-a: Sidrena WordPress i Sidrena WooCommerce.
* Build provjera ruši workflow ako se vrati generički root `sidrena.php`, `static-php`, dodatna edicija ili datoteke izvan korijena pojedinog ZIP paketa.
* Sidrena admin menu ikonica neutralizira se nakon registracije WordPress menija, tako da se prilagođena SVG oznaka više ne prikazuje u bočnom WordPress meniju.
* Dodan je Admin polish guard workflow koji provjerava zaštitu admin menu ikonice i sprječava slučajno vraćanje privremenih workflowova u release liniju.
* Dodan je compliance/automation watchdog koji centralno prati NN 101/2026, NN 105/2026 i pojašnjenja Ministarstva gospodarstva od 22.09.2026.
* Watchdog automatski obnavlja javnu Sidrena stranicu, upload direktorije, zaštitne index datoteke i zapisuje lokalni audit log bez slanja podataka izvan WordPress instalacije.
* Compliance watchdog sada automatski popravlja obavezne tehničke postavke, dnevni cron i publication watch kada je sigurno moguće.
* Audit log je production hardening slojem ograničen po veličini poruke/konteksta, čuva najviše 5000 zapisa i tiho se preskače ako tablica još nije spremna.
* Version metadata, README i edition readme datoteke usklađeni su s finalnom 0.5.0 release pripremom i službenim ZIP nazivima.
* Nova legal automation CI provjera čuva referentne datume 10.09.2026. i 02.05.2025., rano automatsko generiranje, strict publication, failure notifications i hourly publication watch.
* Release priprema za 0.5.0 dodatno učvršćuje zahtjev da se ne objavljuju lokalni, generički ili lažni paketi.
* Dodan je legal automation hardening sloj koji normalizira rizične postavke objave pri spremanju i runtime čitanju.
* Automatizacija vraća generiranje prije 08:00, zadržava arhivu najmanje 30 dana i uključuje CSV/XML, javni HTML, manifest, strict publication i upozorenja o grešci.
* NN 101/2026 + NN 105/2026 smoke test sada provjerava i automatizirane zaštite uz postojeću shemu proizvoda/usluga.

= 0.4.0 =
* Javni cjenik usluga koristi bounded server-side paginaciju od 10 do 100 stavki, zadano 50.
* Admin compliance audit usluga obrađuje zapise u batchovima od 250 i više ne koristi unbounded upit.
* WordPress CSV katalog import obrađuje retke streaming pristupom umjesto akumuliranja do 50.000 redaka u memoriji.
* WordPress XML import koristi XMLReader kada je dostupan i zadržava NONET te zabranu DOCTYPE/ENTITY deklaracija.
* CSV/XML row-limit validacija odvija se prije poslovnih promjena; prevelik import se odbija prije djelomičnog unosa.
* Woo sidrena i location CSV import rade row-limit preflight prije obrade i više ne završava djelomičnim importom uz success rezultat.
* Release build je reproducibilan i postojeći release rerun više ne overwritea assete.

= 0.3.0 =
* Javna arhiva cjenika grupirana je po datumu objave.
* `[sidrena_arhiva]` i arhiva na stranici Objava cjenika koriste isti card/download prikaz.
* Trenutno aktivne CSV/XML datoteke više se ne dupliciraju u odjeljku prethodnih objava.
* Arhivske datoteke se dedupliciraju po nazivu, filtriraju po lokaciji i sortiraju newest-first; zapisi bez datuma ostaju dostupni na kraju.
* Poboljšan je keyboard focus state za otvaranje i zatvaranje dnevnih arhivskih grupa.
* Uklonjen je zastarjeli CSS ravne archive liste.

= 0.2.0 =
* Razvojni ciklus 0.2.0 otvoren za skalabilniju Objavu cjenika, poboljšanja pristupačnosti, stabilnosti i release provjera.
* PDF podrška prikazuje stvarnu verziju paketa, a release/CI provjere više ne ovise o hardkodiranoj verziji 0.1.0.
* Javni HTML cjenik koristi streaming JSONL snapshot umjesto učitavanja cijelog JSON kataloga u PHP memoriju.
* Dodane su server-side pretraga cijelog cjenika i paginacija od 10 do 100 stavki po stranici, zadano 50.
* Uklonjena je ovisnost javnog cjenika o JavaScript filtriranju; pretraga i navigacija rade kao obični GET zahtjevi.
* Woo location-history dnevni snapshot koristi bounded keyset batch obradu.
* Javni snapshot koristi short-write-safe atomic writer s flush/fsync zaštitom.
* Strict validacija odvija se unutar streaming writera pa je uklonjen zaseban puni preflight prolaz kroz katalog.
* Nova lokacijska objava postaje aktualna tek nakon uspjeha svih traženih formata i, kada je uključen, javnog HTML snapshota; neuspjeli novi fajlovi se uklanjaju, a prethodna valjana objava ostaje aktivna.
* Woo REST paginacija računa stvarne javne stavke: jednostavan proizvod ili varijacija je jedna stavka, a variable parent se ne broji zasebno.
* Woo REST skupe cijene/meta/lokacijske podatke učitava samo za stavke tražene stranice.

= 0.1.0 =
* Prvo javno izdanje Sidrene.
* Dva fizički i runtime odvojena plugina: Sidrena WordPress i Sidrena WooCommerce.
* Sidrena WordPress može povezati postojeći javni WordPress tip sadržaja s vlastitim katalogom.
* Automatsko prepoznavanje uobičajenih meta ključeva postojeće cijene i batch sinkronizacija većih kataloga.
* Povezani WordPress zapisi automatski prikazuju sidrenu cijenu bez ručnog shortcodea.
* Sinkronizacija uklanja zastarjelu javnu cijenu ako praćena izvorna cijena više ne postoji.
* Sidrena WooCommerce koristi postojeće WooCommerce proizvode i varijacije bez duplog kataloga.
* Sidrena cijena automatski se dodaje WooCommerce price HTML-u, uz zaštitu od dvostrukog umetanja.
* Compatibility layer za WooCommerce blokove i popularne page-builder prikaze.
* CSV/XML cjenici, javni HTML cjenik, REST, JSON manifest i javna arhiva 30+ dana.
* Automatska stranica Objava cjenika stvara se pri aktivaciji kada je javni HTML uključen.
* Dnevno generiranje zadano je u 06:30, uz sigurnosni watchdog za propuštenu dnevnu objavu.
* Više lokacija i zaseban webshop objekt.
* Povijest cijena u WooCommerce izdanju i tehničke kontrole za 30-dnevnu referencu.
* Spriječena istodobna aktivacija WordPress i WooCommerce izdanja.
* Safe-uninstall ponašanje čuva zajedničke poslovne podatke po defaultu.
