Sidrena changelog

= 2.0.0 =
* Projekt razdvojen na dva potpuno odvojena WordPress plugina: Sidrena WordPress i Sidrena WooCommerce.
* Uklonjen je generički plugin entrypoint; svaki paket sada ima vlastiti plugin header i vlastiti slug.
* Sidrena WordPress koristi isključivo vlastiti WordPress katalog proizvoda i usluga.
* Sidrena WooCommerce koristi isključivo WooCommerce proizvode/varijacije i deklarira WooCommerce kao obaveznu ovisnost.
* Uklonjeno je automatsko prebacivanje načina rada ovisno o tome je li WooCommerce trenutno aktivan.
* WordPress paket više ne sadrži Woo product/history/location/bulk/import/compatibility klase.
* WooCommerce paket više ne sadrži standalone WordPress katalog klasu.
* Admin, REST, cjenici, Site Health, capability logika i DB schema sada poštuju eksplicitno izdanje.
* Woo product/location history tablice kreiraju se samo u WooCommerce izdanju.
* Dodani su zasebni runtime smoke testovi za oba izdanja.
* Dodan je jedan reproducibilni build skript koji iz istog izvora stvara oba izolirana ZIP-a.
* GitHub Release objavljuje samo dva instalacijska paketa i njihove SHA-256 checksumove.

= 1.6.6 =
* Ispravljen prikaz Sidrena top-level admin menija za administratore kojima custom manage_sidrena capability još nije propagiran.
* Dodani manage_options/manage_woocommerce fallback i capability regresijski test.

= 1.6.5 =
* WordPress bez WooCommercea dobio punopravni katalog, REST, Site Health i no-Woo runtime test.
* Poboljšani standalone import, streaming velikih kataloga, hrvatski XML i sigurnosne provjere.

= 1.6.4 =
* Poboljšanja stabilnosti, administracije, dokumentacije i javnog cjenika.
